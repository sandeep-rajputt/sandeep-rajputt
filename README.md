**What I'm working on:**

Right now I'm building [**Opsignal**](https://github.com/sandeep-rajputt) — a multi-tenant workspace platform. It's the kind of project where nothing is handed to you: I've had to figure out workspace isolation, token rotation auth, Redis caching, and Razorpay payment flows from scratch. That's the work I enjoy.

Before that, I built [**Formify**](https://github.com/sandeep-rajputt) — a form builder where users can describe what they want in plain English and an AI assistant (Tivora) generates the form for them. MongoDB, Zod, Next.js 15.
